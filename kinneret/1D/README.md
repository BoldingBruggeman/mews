Input 1D datasets are available from HydroShare:

https://www.hydroshare.org/resource/75547ec09a0d4252982871c228615232/

Download the dataset and place it in:

| Folder      | Description              | hydroshare link
| ----------  | ------------------------ |-----------------
| Hypsograph  | lake hypsograph          |https://www.hydroshare.org/resource/75547ec09a0d4252982871c228615232/data/contents/Hypsograph
| Meteorology | Meteorological forcing   |https://www.hydroshare.org/resource/75547ec09a0d4252982871c228615232/data/contents/Meteorology
| Rivers      | River inflows            |https://www.hydroshare.org/resource/75547ec09a0d4252982871c228615232/data/contents/Rivers
| OBS         | Observations             |https://www.hydroshare.org/resource/75547ec09a0d4252982871c228615232/data/contents/OBS
| Dust        | Dust forcing             |https://www.hydroshare.org/resource/75547ec09a0d4252982871c228615232/data/contents/Dust

* Note: When running gotm-selmaprotbas model, all input files should be in the same folder as the executable (not under sub-folders).
