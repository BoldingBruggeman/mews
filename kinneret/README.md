Large input datasets are not stored in the repository and are available separately via HydroShare.

https://www.hydroshare.org/resource/930c7511a9e74d7780566cd1c3694246/

Download the dataset and place it in:


```text
data/
├── ERA5/           # meteorological forcing
├── ERA5_ssrd/      # shortwave radiation forcing
├── Bathymetry/     # lake bathymetry
├── Rivers/         # river inflows
├── inputs/         # model initial conditions
└── 1D/
    ├── OBS/        # observations
    └── .dat files/ # all 1D input files (no sub-folders)
```
